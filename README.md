# Марковские модели текстов разных авторов СМАЛТ

Цепи Маркова первого порядка по буквам и по классам «гласная/согласная» для эталонных текстов
корпуса СМАЛТ.
Результаты и выводы собраны в [`results/summary.md`](results/summary.md).

## Запуск

```bash
# 1) один раз: прочитать дамп СМАЛТ (без выполнения SQL) и собрать корпус
python scripts/build_corpus.py --config config.json

# 2) эксперимент: матрицы, рисунки, отчёт
python -m markov.cli --manifest data/manifest.csv --config config.json --output results/

# 3) тесты
python -m unittest discover -s tests -t .
```

**Показ вычислений на встрече:** двойной щелчок по `run_demo.bat` или `python scripts/live_demo.py`.
Сценарий из 9 шагов заново считает всё на глазах: корпус, пары букв, тесты, модели, сравнение, Хмелёв,
«внутри и между». Между шагами ждёт Enter, сами вычисления занимают около 10 с. В конце предлагает
открыть `results/demo.html`. Файлы в `results/` не перезаписываются. Каждый шаг сопровождается пояснениями
простыми словами («Что делаем», «Зачем», «Что видно»). Флаг `--short` убирает пояснения, флаг `--no-pause` — паузы.

**Интерактивные страницы:** `python scripts/build_demo.py` (после шага 2, около 2 с) собирает из
`demo/template.html` и результатов расчёта три версии. Все тёмные, открываются двойным щелчком, данные встроены:

| Файл | Для чего |
|---|---|
| `results/demo.html` | показ на проекторе, без пояснений |
| `results/demo_text.html` | для отправки: пояснения у каждого раздела, нейтральные формулировки; тексты пояснений — в `demo/text_version.json` |
| `results/demo_explained.html` | подготовка: блоки «Простыми словами / Зачем» (в репозиторий не входит) |
| `results/markov_smalt_demo.zip` | `demo_text.html` в архиве для почты |

Числа внутри текстов пояснений (56 %, 78 % против 46 %, 6 из 7 и т. п.) записаны вручную в шаблоне и в
`demo/text_version.json`. После пересчёта с другими данными их нужно проверить; графики и таблицы обновляются сами.

Шаг 1 ожидает дамп по пути `source.dump_path` из `config.json`
(`../04_Данные_СМАЛТ/smalt.sql.20260115.070144.gz`) и сверяет его SHA-256 с конфигурацией.
Полный прогон шага 2 занимает около 30 с. При повторном запуске получаются байт-в-байт те же CSV и `summary.md`.

Зависимости перечислены в `requirements.txt`: Python ≥ 3.10, NumPy, Matplotlib, NetworkX.
Pandas и pytest не нужны.

## Структура

| Путь | Что там |
|---|---|
| `config.json` | seed, критерии отбора, авторы, исключения, алфавит, классы V/C, пороги |
| `markov/smalt_dump.py` | потоковый разбор `INSERT … VALUES` из mysqldump; служебные таблицы запрещены белым списком |
| `scripts/extract_smalt.py` | извлечение литературных таблиц в `data/private/` |
| `scripts/build_corpus.py` | отбор текстов, восстановление порядка слов, проверка орфографии, `data/manifest.csv` |
| `markov/preprocess.py` | нормализация (NFC, регистр, ударения, латинские двойники), сегменты, V/C |
| `markov/transitions.py` | N и P; NaN для строк без переходов |
| `markov/compare.py` | равные выборки, расстояние между моделями, разности, внутри/между авторами, проба по Хмелёву |
| `markov/plots.py`, `markov/report.py`, `markov/cli.py` | рисунки, отчёт, запуск |
| `demo/template.html`, `demo/text_version.json` | шаблон интерактивных страниц; тексты пояснений для `demo_text.html` |
| `scripts/build_demo.py` | сборка трёх версий страницы и архива для отправки |
| `scripts/live_demo.py`, `run_demo.bat` | сценарий живого показа вычислений по шагам |
| `scripts/subcorpus_probe.py` | проба по Хмелёву внутри одного журнала и без слов с заглавной буквы → `results/subcorpus_probe.{csv,md}` |
| `scripts/paper_figures.py` | чёрно-белые рисунки для тезисов → `results/paper/` |
| `tests/` | 23 теста: случаи из ТЗ (`абба`, `мама`, `а а`, `объект`, границы файлов, NaN, ё/ѣ/і, воспроизводимость) и разбор кодировки |
| `data/manifest.csv` | 107 отобранных текстов: происхождение, статус атрибуции, издание, орфографическая статистика |
| `data/excluded_texts.csv` | тексты выбранных авторов, не вошедшие в корпус, с причиной |
| `results/` | `summary.md`, CSV с матрицами и метриками, `figures/` |

## Ключевые решения

- **Отбор.** Берутся тексты с `AUTHOR_VERIFY=1` («Эталон»), `STATUS=2` («Статья проверена»),
  `CATEGORY=0` и `INUSE1=1`. Смысл кодов взят из pysmalt (`templates/text_app/import_form.html`,
  `text_app/models/tbl_text.py`).
- **Порядок слов.** Слова сортируются по `CHAPTER_INDEX, PARAGRAPH_INDEX, SENTENCE_INDEX, WORD_INDEX, ID_WORD`.
  Поле `WORDORDER` часто равно 0, поэтому не используется.
- **Орфография** сохраняется дореформенной. Латинская `i`, набранная вместо `і`, исправляется, но только внутри
  кириллических слов. Текст с ъ, но без ѣ (частичная модернизация при наборе) исключается автоматически.
- **Переходы считаются только внутри слова.** ъ/ь входят в буквенную модель как буквы, а в модели V/C разрывают цепочку.

## Конфиденциальность

`data/private/` (извлечённые таблицы) и `data/raw/` (тексты) не публиковать. Дамп СМАЛТ содержит служебные
таблицы пользователей и сессий; этот код их не читает: запрос таблицы вне белого списка даёт `PermissionError`.
